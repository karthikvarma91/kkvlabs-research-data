# Citation Source Map, September 2026

What this is: for six local-service industries (med spas, roofers, dentists, personal injury
law firms, chiropractors, HVAC companies), when Google AI Mode names local businesses for a
buyer-intent query ("best <industry> in <city>"), which sources it cites alongside them. Every
number in this dataset and in the write-up it came from is read from `citation-sources.json`,
generated by `tools/aggregate_sources.py` from the raw captures in
`tools/aimode-sources/<industry>/<city-slug>.json`
[CITATION-SOURCES-FINDINGS-2026-09-15.md].

## How this was collected

- Engine: Google AI Mode (`google.com/search?udm=50&q=...`), via the account owner's own
  Chrome (the in-app browser throttled on a prior attempt).
- Query pattern: "best <industry singular> in <City, State>", one query per city. Cities were
  taken in file order from each industry's own `*-cities.json` in kkvlabs-landing, not sampled.
- Per query: navigate, wait 10 to 12 seconds for the AI Mode answer to render, then capture the
  visible answer text and a deduped list of link tokens computed in-page from every anchor on
  the page.
- Link tokens, not raw hrefs: any URL carrying Google's own tracking query string gets redacted
  by the browsing tool's data-loss-prevention filter, so every anchor is reduced in-page to one
  token per unique link: the bare hostname for non-Google domains, or `<host>/maps` /
  `<host>/<first two path segments>` for any google.* host. This means the map counts domains,
  not exact URLs, and cannot show which specific business a Google Maps citation pointed to
  when more than one appeared in the same answer, only that at least one did
  [CITATION-SOURCES-FINDINGS-2026-09-15.md].
- Separating the answer's own citations from Google's fixed page chrome (sign-out, search
  personalization, Travel/Finance tab shortcuts, Policies, Support articles, the map scaffolding)
  used an explicit allowlist of Google host and path prefixes, not DOM position, since the
  collection step kept only a deduped token set rather than per-link coordinates.
  `google.com/maps` and `maps.google.com/maps` were deliberately kept out of that exclusion list
  and counted as citations, since a Maps link points at a specific named business.
- Domain classification: each surviving token's host is matched against a fixed list of
  directory and community domains (Yelp, RealSelf, Avvo, Justia, FindLaw, Healthgrades, Zocdoc,
  Angi, HomeAdvisor, BBB, Reddit, Facebook, Instagram, Nextdoor, YouTube, Super Lawyers, Best
  Lawyers), a small news-domain list plus a suffix heuristic, or the business's own domain
  (matched against the business names Google itself named for that city). Anything left over is
  bucketed as an unclassified "other" directory or site.
- Share % = the percentage of captured answers (one per city) citing at least one token of that
  type. An answer can cite more than one type, so shares in a row do not sum to 100.
- Total answers captured: 123 across all six industries (20 to 21 per industry). At this sample
  size, treat every percentage as plus or minus roughly one answer's worth of noise, about 5
  points at n=20 [CITATION-SOURCES-FINDINGS-2026-09-15.md].

## Files

- `citation-sources.json`: the full aggregate, one object with `method`, `industries` (keyed by
  industry slug, each carrying its captured cities, capture dates, per-source-type share, and
  its own top domains list), `top_domains_overall` and the two total-answers-captured counters.
  This is a straight copy of `kkvlabs-outreach/research/citation-sources-2026-09.json`, the file
  the live report page reads from at build time.

## Known limitations

- 20 to 21 cities per industry is a moderate, still-directional sample, not a precision
  measurement [CITATION-SOURCES-FINDINGS-2026-09-15.md].
- `google.com/maps` counts an answer as citing a Google Business Profile if any business card in
  it linked to Maps; it does not attribute the citation to a specific business when several
  appeared in the same answer.
- "Business's own site" matching is a slug substring match against the `aiNamed` list already
  recorded for that city in the landing repo's `*-cities.json` files, not a fresh lookup of
  every business's real domain; a business AI Mode named that is not already in that list for
  that city falls into the "other" bucket instead.
- A small number of answers carried no non-chrome link tokens at all (the local pack rendered
  ratings and addresses with no clickable Maps or business-site anchor for that render); those
  answers count as citing zero source types, which pulls every share down slightly rather than
  inflating it.
- No single named directory or community source type exceeded the business's own-site share
  inside its own industry in this sample; the highest is Justia at 61.9 percent of law firm
  answers, against 81.0 percent for the firms' own sites
  [CITATION-SOURCES-FINDINGS-2026-09-15.md].
